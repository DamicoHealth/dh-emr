Guides

Three guides cover DH EMR. Start with the first one.

  • Getting started: set up a device with the wizard, enter your first visit, take your first backup
  • User guide: day-to-day work - entering visits, finding patients, the flow board, analytics, sync, and what the warning banners mean
  • Admin guide: for whoever runs the organization - standing up your cloud project, choosing field or clinic mode, customizing forms, formulary and lists, and managing staff and devices

Not ready to set up a real device? The demo is a fictional clinic with sample patients where you can try everything safely.
